1. Quiz-day rules and steps

Rules from class

  • Each coding task gets exactly one graph. More or fewer graphs lose points (applies to the test too).
  • Use only functions taught in class. Anything else can cost points. AI tools are allowed only with class material.
  • The radar exercise says: avoid unnecessary variables, repeated logic, redundant functions, or code that does not directly produce the graph. Points are deducted for redundant code.
  • A line plotted over t must have y-values with the same number of points as t, even for a constant line (3000 + 0*t).
  • Some important coding details (arguments, settings, error handling) were taught only in class exercises, so your own notes matter too.

Step by step on quiz day

  1. Run the imports cell first (see section 2).
  2. Load the CSV: df = pd.read_csv('file.csv') then df.head() to see the column names.
  3. Read the task. Ask: what am I comparing? Pick the chart from the finder (section 3).
  4. Start each graph with plt.figure(figsize=(5, 3)) and end it with plt.show().
  5. If asked for a finding, write one plain sentence about what the graph shows.
  6. Export: !jupyter nbconvert --to html yourfile.ipynb (keep the notebook in the content folder).
  7. Check: how many graphs did each task produce? Exactly one.

Pie vs count plot

  • Pie or donut works best with 5 labels or fewer. With more slices, people cannot compare angles and areas.
  • More than five labels: use a count plot. Bars share a common baseline, so differences are easy to see.

6. Numeric variable across groups (multivariate)

Box plot, violin plot

Use when: comparing median, spread and outliers across groups (box) or the full shape (violin).

sns.catplot(data=df, x='gender', y='math_score', kind='box',
            hue='gender', palette={'female':'hotpink', 'male':'skyblue'})
plt.show()

sns.violinplot(data=df, x='gender', y='math_score', hue='gender',
               palette={'female':'hotpink', 'male':'skyblue'})
plt.show()

Box plot anatomy: box from Q1 to Q3, line at the median, whiskers, dots for outliers. Whiskers do not always reach the true min and max. The true min and max can be among the outliers.

IQR         = Q3 - Q1
Lower limit = Q1 - 1.5 * IQR
Upper limit = Q3 + 1.5 * IQR      # points outside the limits are outliers

catplot with kind='box' is used when x is categorical and y is numeric. Outliers matter in real data because they flag errors, rare events and unusual groups.

KDE by group

Trend line (degree-2 fit)

Use when: showing the overall direction of a series.

8. Analytical models

Rule and the five patterns

Every line you plot over t needs y-values from the same t (same number of points), even a constant line: 3000 + 0*t.

PatternModelWhy
Savings that speed up2000 + 2*t**2Starts at 2000, grows non-linearly
Seasonal demanda + b*np.sin(2*np.pi*doy/365 + c)Repeats yearly; flat most of the year, peak in December
Shopping browsingrandom walk with np.cumsumA wandering path
Learningplt.step(..., where='post')Plateaus then rapid jumps
Rich vs poorpower law (lomax_pdf)A few hold most of the wealth

Seasonal demand (sine)

def xmax_demand(dates, a=1, b=1, c=np.pi*(3/4)):
    doy = dates.dayofyear
    demand = a + b*np.sin(2*np.pi*doy/365 + c)
    return demand

dates = pd.date_range('2026-01-01', '2026-12-31', freq='D')
demand = xmax_demand(dates)

plt.figure(figsize=(8, 3))
plt.plot(dates, demand, color='green', linewidth=2)
plt.xticks(pd.date_range(dates.min(), dates.max(), freq='MS'), rotation=45)
plt.axhline(y=0, color='red', linestyle='--')
plt.axhline(y=2, color='red', linestyle='--')
plt.show()

dayofyear gives 1 to 365. freq='D' daily, freq='MS' month start. a = baseline, b = size of the swing, c = shifts when the peak happens. plt.axhline draws a horizontal reference line.

Power law (rich and poor)

def lomax_pdf(r, alpha):
    return alpha * (1 + r) ** (-(alpha + 1))

r = np.linspace(1, 10, 100)
alpha = 1.5
prob = lomax_pdf(r, alpha)

plt.figure(figsize=(6, 3))
plt.plot(r, prob)
plt.axvline(6, color='grey', lw=1.2, ls='--')
plt.fill_between(r, prob, where=(r>=1) & (r<=6), color='gray', alpha=0.4)
plt.fill_between(r, prob, where=(r>=6) & (r<=10), color='gold', alpha=0.6)
plt.show()

fill_between(r, prob, where=...) shades the area under the curve for the chosen range.

Supply and demand (LA housing)

t = np.linspace(0, 3, 50)
s = np.sin(t)                    # supply
d = np.exp(t)*0.1                # demand

plt.figure(figsize=(6, 3))
plt.plot(t, s, label='supply', color='green', lw=2)

plt.axvline(x=0.1, color='grey', linestyle='--')
plt.legend()

# constant inventory, still a function of t, as its own graph

plt.figure(figsize=(5, 3))

Equilibrium is where supply equals demand (the lines cross, near t = 0.1 and t = 2.13 in class). After 2.13, demand is above supply, which means a housing shortage.

Linear and non-linear with two sliders

def linear_func(slope, intercept):
    x = np.linspace(-10, 10, num=1000)
    plt.ylim(-10, 10)
    plt.axvline(color='black')
    plt.axhline(color='black')
    plt.plot(x, slope*x + intercept, lw=5, color='red')
    plt.grid()
    plt.show()

interactive_plot = interactive(linear_func, slope=(-5.0, 5.0), intercept=(-5.0, 5.0))
interactive_plot

def nonlinear_func(slope, intercept):
    x = np.linspace(-10, 10, num=100)
    plt.ylim(-10, 10)
    plt.axvline(color='black')
    plt.axhline(color='black')
    plt.plot(x, x**2 + slope*x + intercept, lw=5, color='blue')
    plt.grid()
    plt.show()

interactive_plot = interactive(nonlinear_func, slope=(-5.0, 5.0), intercept=(-5.0, 5.0))
interactive_plot

interactive(func, a=(low, high)) makes a slider per argument. plt.ylim fixes the y range so the picture does not jump.

Normal distribution probability

x_all = np.linspace(-4, 4, 200)
y_all = norm.pdf(x_all)

def func_area(x=0):
    plt.figure(figsize=(7, 3))
    plt.plot(x_all, y_all, linewidth=2)
    x_fill = np.linspace(-4, x, 200)
    y_fill = norm.pdf(x_fill)
    plt.fill_between(x_fill, y_fill, 0, alpha=0.35)
    plt.axvline(x, linestyle="--", linewidth=2, color='red')
    area = norm.cdf(x)
    plt.xlim(-4, 4)
    plt.title(f"P(Z ≤ {x:.2f}) = {area:.4f}")
    plt.show()

interact(func_area, x=(-4, 4, 0.01));

norm.pdf = height of the bell curve. norm.cdf = area to the left of x = probability. interact(func, x=(min, max, step)) adds a slider.

10. 3D visualization

Surface from a formula

Use when: drawing a function of two variables.

x_d = np.linspace(-1, 5, 10)
y_d = np.linspace(-1, 5, 10)
X, Y = np.meshgrid(x_d, y_d)          # grid of all x, y pairs
Z = 2*X + Y + 5                        # third dimension

fig = plt.figure(figsize=(8, 6))
ax = fig.add_subplot(projection='3d')
ax.plot_surface(X, Y, Z, color='orchid', alpha=0.8)
plt.show()

# other class formulas (x, y = np.linspace(1, 10, 100))
Z = np.log(X**2 + Y**2)                # use cmap='cool'
H = np.sin(np.sqrt(X**2 + Y**2))       # use cmap='gnuplot'
ax.plot_surface(X, Y, H, cmap='gnuplot')

Steps: 1) linspace for x and y, 2) meshgrid, 3) compute Z (or H), 4) fig.add_subplot(projection='3d'), 5) ax.plot_surface, 6) plt.show(). cmap colors by height.

12. Network visualization

Concepts

  • Node: an entity (person, computer, organization).
  • Edge (link): a relationship between nodes. Directed = one-way arrow, undirected = two-way.
  • Degree: number of connections a node has. Directed networks have in-degree and out-degree.
  • Business use: find influencers and key connections, detect groups with similar behavior for targeting.

Build and draw a small directed network

G = nx.DiGraph()
G.add_node('a')
G.add_node('b')
G.add_node(6)
G.add_edge('a', 'b')        # a -> b
G.add_edge('a', 6)          # a -> 6
G.add_edge('b', 6)          # b -> 6

plt.figure(figsize=(4, 4))
pos_G = nx.spring_layout(G)
nx.draw_networkx_nodes(G, pos_G, node_color='gold', node_size=500)
nx.draw_networkx_edges(G, pos_G, edge_color='green',
                       connectionstyle='arc3, rad=0.2', min_target_margin=10)
nx.draw_networkx_labels(G, pos_G)
plt.show()

spring_layout decides node positions. draw_networkx_nodes/edges/labels are three separate calls that together make one graph. connectionstyle='arc3, rad=0.2' curves the arrows. min_target_margin keeps the arrowhead off the node. The class PDF cut off the exact rad value for one example; 0.2 is the filled-in value.

16. Survival analysis for business

The business question

  • Research question: how long does a trendy product stay popular before its popularity declines substantially?
  • Data: 60 viral products (Stanley cups, Pokemon cards, Labubus). Each row is one product observed from the start of its trend.
  • influencer_push: 1 = influencer promotion, 0 = none. discount_support: 1 = discounts used.
  • months_observed: months from start until decline or end of observation.
  • outcome: 1 = popularity fell below 40% of launch level; 0 = it had not (still popular when observation ended, called censored).
  • Answers: what share of products is still popular after 6, 12 or 18 months, and the popularity lifespan.
  • Value: plan inventory, marketing, pricing, launches. Compare products with and without influencer promotion.

Weibull formula

S(t) = exp[ -( t / lambda )^k ]
  • S(t) is the survival probability at time t. It never increases.
  • Large lambda: longer survival, slower decline.
  • k < 1: survival drops fast at first, then flattens.
  • k = 1: exponential (typical constant-rate decline).
  • k > 1: survival drops slowly at first, then sharply.
t = np.linspace(0, 12, 100)
s_t = np.exp(-(t/3)**0.5)                    # lambda = 3, k = 0.5
plt.figure(figsize=(5, 3))
plt.plot(t, s_t, label='chance of survival', color='green', lw=3)
plt.grid()
plt.legend()
plt.show()

Interpretation from class: as time progresses, the chance of survival gradually decreases.

19. Rapid-fire self-test

Cover the answer, then reveal

1. A column has 8 labels. Pie chart or count plot?

Count plot. Pie is for 5 labels or fewer.

2. What does np.linspace(0, 10, 5) return?

[0, 2.5, 5, 7.5, 10]. Five numbers, both ends included.

3. What does df.iloc[:, 0:11] select?

All rows, columns 0 to 10. The end (11) is excluded.

4. Which chart compares math score by gender?

Box plot (catplot kind="box"), violin, point plot, or KDE with hue.

5. Where do box plot whiskers end?

At the last point inside the outlier limits, not at the true min and max.

6. What are the outlier limits?

Q1 - 1.5 x IQR and Q3 + 1.5 x IQR, where IQR = Q3 - Q1.

7. What does common_norm=False do?

Scales each group's KDE separately so group sizes do not distort the comparison.

8. What does a heatmap cell of 0.9 mean?

Strong positive linear relationship. It does not prove causation.

9. Which two steps come before np.polyfit on dates?

pd.to_datetime, then map(pd.Timestamp.toordinal).

10. What does errorbar=("pi", 100) show on a point plot?

The full min-to-max range instead of the 95% confidence interval.

11. In the social media network, Carmen has degree 4. What does it mean?

Carmen has 4 connections, the most, so Carmen is the biggest node.

12. Why remove stop words in a word cloud?

They carry little meaning and would be the biggest words, hiding the themes.

13. Weibull k < 1: what does the survival curve look like?

Drops fast at first, then flattens.

14. In the survival data, what does outcome = 0 mean?

Popularity had not fallen below 40% when observation ended (censored).

15. In the bubble chart, what sets bubble size?

Num_Purchase (x = Mentions, y and color = Sentiment).

16. Which model fits learning with plateaus?

A step function: plt.step(weeks, level, where="post").

17. Why repeat the first value in a radar chart?

To close the shape so the outline returns to its start.

18. How do you plot a constant line over t?

Make y a function of t, e.g. 3000 + 0*t, so it has the same number of points.

19. In the housing model, what happens after t = 2.13?

Demand rises above supply, so there is a shortage.

20. What does norm.cdf(x) give?

The area to the left of x, i.e. the probability P(Z <= x).
